# Grok

1. Open [grok.com/connectors](https://grok.com/connectors), then **New Connector**
2. Choose **Custom** and paste the server URL: `https://mcp.novadata.io/api/mcp`
3. Sign in to Nova and allow access
4. Ask your first question:

```
How many days of stock do my top 5 SKUs have?
```

Step by step: [novadata.io/amazon-ai-agents/connect-grok](https://novadata.io/amazon-ai-agents/connect-grok)
