# Gemini

1. Open **Settings** > **Connected Apps**
2. Add a custom app with the server URL `https://mcp.novadata.io/api/mcp`, then **Next**
3. Follow the sign in to Nova and allow access
4. In a chat, type **@** and pick **Nova**

```
@Nova What was my best day for net profit this month, and what drove it?
```

Step by step: [novadata.io/amazon-ai-agents/connect-gemini](https://novadata.io/amazon-ai-agents/connect-gemini)
